## 📖 Deskripsi Proyek

Adventure Camp merupakan aplikasi berbasis console yang dikembangkan menggunakan bahasa pemrograman C untuk mengelola penyewaan peralatan camping.

Program ini dirancang untuk memudahkan pengguna dalam melihat daftar peralatan, melakukan penyewaan beberapa jenis barang dalam satu transaksi, menghitung biaya sewa secara otomatis, serta mencatat riwayat transaksi dan total pendapatan.

Aplikasi ini juga menyediakan fitur pemberian diskon berdasarkan lama penyewaan dan pencetakan struk transaksi sebagai bukti penyewaan.

## ✨ Fitur Utama

- 📋 Menampilkan daftar peralatan camping.
- 🎒 Menyewakan beberapa jenis peralatan dalam satu transaksi.
- 🧮 Menghitung biaya penyewaan secara otomatis.
- 💸 Memberikan diskon berdasarkan lama penyewaan.
- 🧾 Mencetak struk transaksi penyewaan.
- 📚 Mencatat riwayat transaksi.
- 💰 Menampilkan total pendapatan dari transaksi penyewaan.

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman:** C
- **Jenis Aplikasi:** Console Application
- **Compiler:** GCC atau compiler C lainnya

## 🚀 Cara Menjalankan Program

1. Pastikan compiler C, seperti GCC, sudah terpasang.
2. Clone repository ini:

   ```bash
   git clone https://github.com/USERNAME/Adventure-Camp.git
   ```

3. Masuk ke folder proyek:

   ```bash
   cd Adventure-Camp
   ```

4. Kompilasi program:

   ```bash
   gcc main.c -o adventure-camp
   ```

5. Jalankan program.

   **Windows:**

   ```bash
   adventure-camp.exe
   ```

   **Linux/macOS:**

   ```bash
   ./adventure-camp
   ```
